# 五大 AI 岗位学习路线与规划

> 基于 2026 年 8 月最新招聘 JD 整理，覆盖 AI 应用工程师、AI Agent 开发工程师、AI Agent 研发工程师（AI Native 创新小组）、AI Agent 开发（滴滴）、AI Agent 应用开发工程师（智能内控方向）五个岗位。

---

## 岗位一：AI 应用工程师（25-50K·16薪）

**岗位画像**：偏向大模型应用层工程开发，兼顾 Agent 编排、多模态服务、模型网关、评测监控体系，属于业务落地型 AI 后端岗位。重点考察线上生成式 AI 落地经验、服务 SLA 治理、工程规范化沉淀能力。

### 核心技能要求
- Python Web 服务基础（FastAPI/Flask）
- Agent 编排与多步骤任务自动化
- MCP 工具调用协议、自定义 Skills 插件开发
- RAG 全链路优化、Prompt 约束与检索增强
- 模型网关搭建（负载均衡、请求缓存、超时重试、故障降级）
- 评测体系与回归机制（离线评测/在线 A/B）
- 全链路监控告警（质量、延迟、成本、失败率）
- 大数据经验（Spark/Hadoop/Hive）加分

### 学习路线（建议 3-6 个月）

#### 第一阶段：Python 后端基础（4-6 周）
| 模块 | 内容 | 产出物 |
|------|------|--------|
| Python 进阶 | 异步编程（asyncio）、类型注解、装饰器、上下文管理器 | 完成一个异步爬虫项目 |
| Web 框架 | FastAPI 深度掌握（依赖注入、中间件、后台任务、WebSocket） | 搭建一个 RESTful API 服务 |
| 数据库 | SQLAlchemy、Redis 缓存策略、连接池管理 | 实现用户系统 + 缓存层 |
| 部署运维 | Docker 容器化、Gunicorn/Uvicorn、Nginx 反向代理 | 项目 Docker 化部署 |

#### 第二阶段：大模型应用开发（4-6 周）
| 模块 | 内容 | 产出物 |
|------|------|--------|
| LLM API 集成 | OpenAI API、Claude API、国产大模型（通义、文心、讯飞）统一封装 | 多厂商模型网关原型 |
| Prompt 工程 | 系统提示词设计、动态提示词、Few-shot、Chain-of-Thought | 构建一个智能客服机器人 |
| RAG 系统 | 向量数据库（Milvus/Chroma/FAISS）、文档分块、Embedding、重排序 | 搭建企业知识库问答系统 |
| Agent 框架 | LangChain/LangGraph 核心概念、工具调用、记忆管理 | 实现一个多步骤任务 Agent |

#### 第三阶段：工程化与运维（3-4 周）
| 模块 | 内容 | 产出物 |
|------|------|--------|
| 服务治理 | 限流熔断（Circuit Breaker）、负载均衡、动态路由 | 模型网关生产级实现 |
| 评测体系 | 离线评测指标设计、在线 A/B 测试框架、回归测试流水线 | 搭建评测平台 |
| 可观测性 | Prometheus + Grafana 监控、日志聚合、告警规则 | 全链路监控大盘 |
| 成本控制 | Token 用量统计、调度策略优化、推理成本分析 | 成本优化方案 |

#### 第四阶段：项目实战（持续）
- **项目 1**：多模态 AI 应用（图文混合场景）—— 支持文本大模型 + 图文多模态混合业务
- **项目 2**：企业级 Agent 工作流平台 —— 可编排、模块化、可复用的服务架构
- **项目 3**：大数据 + AI 融合项目 —— 结合 Spark/Hive 做数据预处理 + 模型推理流水线

### 推荐资源
- **FastAPI**: 官方文档 + 《FastAPI 现代 Python Web 开发》
- **LangChain**: 官方文档 + LangChain Academy 免费课程
- **RAG**: 《Building LLM Apps》+ LlamaIndex 官方教程
- **工程化**: 《Designing Data-Intensive Applications》+ Google SRE 书籍

## 岗位二：AI Agent 开发工程师（20-40K·15薪）

**岗位画像**：核心方向为企业级落地 Agent、私有化国产大模型、业务自动化数字员工。必须有生产上线项目，弱化纯 Demo 竞争力。要求独立部署服务能力。

### 核心技能要求
- Agent 核心能力：任务规划、长短记忆、工具调用、反思纠错、多智能体协同
- LangChain/LlamaIndex 源码级二次封装
- 国产大模型私有化部署、API 对接、兼容适配改造
- 自定义 Tool 工具插件开发（OA/ERP/业务数据库 API 对接）
- 向量库检索优化、分块策略、重排、多路召回
- RAG 与 Prompt 工程、幻觉抑制方案
- Docker/Linux 基础运维、独立部署服务
- Agent 效果量化指标（任务成功率、幻觉率、召回精度）

### 学习路线（建议 4-6 个月）

#### 第一阶段：Agent 基础理论（3-4 周）
| 模块 | 内容 | 产出物 |
|------|------|--------|
| Agent 架构 | ReAct、CoT、ToT、Reflexion 等推理范式 | 手写一个 ReAct Agent |
| 记忆系统 | 短时记忆（Buffer）、长时记忆（Vector DB）、实体记忆 | 实现分层记忆模块 |
| 工具调用 | Function Calling、MCP 协议、工具注册与发现机制 | 开发 3-5 个自定义工具 |
| 任务规划 | 目标分解、子任务调度、依赖管理、并行执行 | 搭建任务规划器 |

#### 第二阶段：框架深度掌握（4-5 周）
| 模块 | 内容 | 产出物 |
|------|------|--------|
| LangChain 源码 | 核心组件（Chains、Agents、Tools、Memory）源码阅读 | 二次封装通用组件底座 |
| LlamaIndex | 索引构建、查询引擎、RAG Pipeline 高级用法 | 企业文档智能问答系统 |
| LangGraph | 状态机工作流、节点编排、条件分支、循环 | 复杂业务流程 Agent |
| 国产模型适配 | 通义千问、文心一言、讯飞星火、ChatGLM 私有化部署 | 多模型统一调用层 |

#### 第三阶段：业务闭环与部署（3-4 周）
| 模块 | 内容 | 产出物 |
|------|------|--------|
| 业务插件开发 | OA/ERP 系统对接、数据库操作、API 封装 | 企业自动化工作流 |
| RAG 高级优化 | Hybrid Search、Reranking、查询重写、多路召回 | 高精度检索系统 |
| 幻觉抑制 | 自我一致性检查、事实验证、引用溯源 | 幻觉率 < 5% 的问答系统 |
| 部署运维 | Docker Compose、K8s 基础、CI/CD、日志监控 | 生产环境部署方案 |

#### 第四阶段：量化评测与交付（2-3 周）
| 模块 | 内容 | 产出物 |
|------|------|--------|
| 评测体系 | 任务成功率、幻觉率、召回精度、响应延迟 | 自动化评测平台 |
| A/B 测试 | 实验设计、指标对比、统计显著性检验 | 线上实验报告 |
| 客户交付 | 需求分析、方案设计、POC 验证、落地交付 | 完整项目案例 |

#### 项目实战建议
- **项目 1**：企业数字员工 —— 打通 OA/ERP/数据库，实现流程自动化闭环
- **项目 2**：私有化知识库 Agent —— 基于国产大模型 + 本地向量库的企业知识问答
- **项目 3**：多智能体协作系统 —— 多个 Agent 分工协作完成复杂业务任务

### 推荐资源
- **Agent 理论**: 《ReAct》论文、《Reflexion》论文、《Generative Agents》论文
- **LangChain**: 官方文档 + GitHub 源码 + LangChain Cookbook
- **部署**: Docker 官方文档 + 《Kubernetes 权威指南》
- **国产模型**: 通义千问、ChatGLM、Baichuan 官方 GitHub 仓库

## 岗位三：AI Agent 研发工程师 — AI Native 创新小组（35-65K·16薪）

**岗位画像**：创新型中高级 Agent 研发岗，区别于普通业务岗。不只写功能代码，要求具备需求评估、方案选型、调试观测、线上运营完整闭环思维，直面大模型天然不确定性难题。

### 核心技能要求
- 独立完成 Agent 架构方案设计，不局限调用开源框架
- 状态机工作流（LangGraph）实现复杂任务编排
- Function Calling + MCP 工具调用协议，开发通用工具网关
- 长短时分层记忆持久化体系
- 多智能体通信、任务协同调度
- Trajectory 轨迹追踪、可观测与回放机制
- 精细化分层指标（上层任务结果 + 中层单步骤执行）
- 成本/复杂度/收益综合判断思维（方案取舍能力）
- 监控告警、兜底与人工接管机制

### 学习路线（建议 6-9 个月）

#### 第一阶段：全栈基础夯实（6-8 周）
| 模块 | 内容 | 产出物 |
|------|------|--------|
| 系统设计 | 设计模式、架构原则、微服务设计、领域驱动设计 | 设计一个 Agent 平台架构 |
| 状态机 | 有限状态机、HFSM、行为树、Petri 网 | 实现复杂工作流引擎 |
| 分布式基础 | 消息队列、分布式锁、一致性协议、CAP 理论 | 分布式任务调度系统 |
| 数据存储 | 关系型数据库、NoSQL、向量数据库、时序数据库 | 多模态数据存储方案 |

#### 第二阶段：Agent 核心研发（6-8 周）
| 模块 | 内容 | 产出物 |
|------|------|--------|
| 自主架构设计 | 从零设计 Agent 系统（不依赖现成框架） | 自研 Agent 框架原型 |
| 记忆体系 | 分层记忆（工作记忆/短期记忆/长期记忆）、记忆压缩、记忆检索 | 记忆持久化系统 |
| 工具网关 | 通用工具注册、权限管理、调用链路追踪、熔断降级 | 企业级工具网关 |
| 多智能体 | Agent 间通信协议、任务分配、冲突解决、共识机制 | 多 Agent 协作平台 |

#### 第三阶段：可靠性工程（4-6 周）
| 模块 | 内容 | 产出物 |
|------|------|--------|
| Trajectory 追踪 | 执行轨迹记录、上下文快照、决策链路可视化 | 全链路追踪系统 |
| 回放调试 | 异常案例复现、状态回滚、断点调试、沙箱执行 | 任务回放平台 |
| 可观测性 | 埋点设计、指标采集、链路追踪、日志分析 | 可观测性平台 |
| 兜底机制 | 自动降级、异常兜底、人工接管、故障转移 | 高可用保障方案 |

#### 第四阶段：评测与运营（4-5 周）
| 模块 | 内容 | 产出物 |
|------|------|--------|
| 分层评测 | 任务级评测、步骤级评测、指标拆解、归因分析 | 评测体系设计 |
| 数据驱动 | 离线评测 + 线上观测双向驱动、策略迭代闭环 | 数据驱动优化方案 |
| 成本管控 | Token 成本核算、推理优化、体验与开销平衡 | 成本优化报告 |
| 方案取舍 | Agent vs 固定流程 vs 单次调用的决策框架 | 方案选型方法论 |

#### 第五阶段：前沿跟踪（持续）
- 跟踪最新 Agent 论文（arXiv 每日更新）
- 参与开源社区（LangChain、AutoGPT、MetaGPT）
- 复现前沿方案并落地业务

#### 项目实战建议
- **项目 1**：自研 Agent 框架 —— 从零构建，支持多智能体协作、记忆持久化、工具调用
- **项目 2**：全链路可观测平台 —— Trajectory 追踪 + 回放调试 + 异常定位
- **项目 3**：智能运维 Agent —— 自动故障诊断、根因分析、修复建议

- **系统架构**: 《Designing Data-Intensive Applications》、《Building Microservices》
- **Agent 论文**: ReAct、Reflexion、AutoGPT、MetaGPT、CAMEL 等论文精读

## 岗位五：AI Agent 应用开发工程师 — 智能内控方向（25-50K·16薪）

**岗位画像**：风控/内控业务线，大数据分布式后端 + 风控 LLM + 企业级 Agent 复合岗。聚焦电商资金、业务合规、大促风险防控，业务属性极强。硬性要求至少 2 年 AI 应用开发，有风控/金融行业经验大幅加分。

### 核心技能要求
- 企业级风控/内控平台后端架构设计、全流程功能开发
- 结合 LLM 构建风险识别模型（资金作弊、违规交易、流程不合规）
- 业务风险建模能力，打通交易、资金、用户多维度数据
- LLM 微调实战：SFT 指令微调、Post-training 领域后训练
- 风控专属垂类模型构建
- 风控知识库 RAG 全链路落地
- 风险归因、合规判断可解释性方案
- 实时分布式决策引擎开发（传统规则策略 + LLM 大模型推理）
- 高并发、低延迟架构优化（双十一峰值海量交易）
- 限流熔断、推理性能调优
- 企业级 Agent、多步骤智能 Workflow 编排
- 双语言精通：Python + Golang

### 学习路线（建议 6-9 个月）

#### 第一阶段：风控业务基础（4-5 周）

|------|------|--------|
| 风控体系 | 反欺诈、反洗钱、信用评估、合规审计、风险定价 | 风控知识图谱 |
| 业务场景 | 电商资金风控、交易风控、内容风控、大促保障 | 场景分析报告 |
| 规则引擎 | Drools、Easy Rules、自研规则引擎 | 规则决策系统 |
| 数据分析 | 风控特征工程、异常检测、关联分析、图计算 | 风险识别模型 |

#### 第二阶段：大数据与分布式（5-6 周）
