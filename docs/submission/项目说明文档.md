## 1. 项目概述

### 1.1 一句话介绍

智面仓把"模拟面试"从"刷题库"升级为**一次完整的、可量化的面试经历**：按岗位 JD 与个人简历动态组卷、逐题限时作答、答得好自动追问、结束前保留反问环节，交卷后输出六维能力雷达与逐题参考答案对照，并直接把薄弱项接到学习路线上。

同时向招聘侧延伸：企业可发布岗位、按匹配度筛选候选人、推进面试看板并提交结构化评估；平台侧提供资质审核、题库与 AI 引擎治理能力。

### 1.2 解决什么问题

| 求职者的问题 | 本作品的应对 |
|---|---|
| 背题库不等于会面试，缺乏"被追问"的压迫感 | 自适应追问：答得好插同技能更高难度题，答得差插更低难度题 |
| 不知道自己的回答差在哪 | 六维评分逐题给证据 + 参考答案要点对照 + 用时与超时分析 |
| 练完就忘，短板没有被补齐 | 薄弱项自动汇入能力画像，并生成分阶段学习路线（含产出物与推荐资源） |
| 题目与岗位不匹配，"练了也没用" | 结构化题库按**岗位大类 + 技能 + 难度**三维组卷，专业题不跨岗位大类 |
| 企业的简历筛选与面试评价是黑箱 | 匹配度可解释、面试评价结构化、流程状态在看板上全透明 |

### 1.3 使用方需要知道的三件事

1. **零配置开箱即用**：不配置任何模型密钥也能完整跑通全流程（内置确定性 Mock 引擎，离线可演示）；接入真实大模型只需在页面上填一次配置。
2. **组卷不串岗位**：321 道结构化题库、20 个岗位大类、88 个技能，专业题严格限定在本岗位大类内；题量缺口由 AI 按 JD 定制生成，不拿别的岗位的旧题填补。
3. **没有依据就不显示**：统计与报告一律来自真实记录，无数据时显示空态或"未知"；模拟评分不写入正式能力画像，正式企业面试拒绝使用模拟评分与模拟报告。

## 2. 功能范围（四端）

### 2.1 公共门户（无需登录）

首页 · 职位广场（搜索与筛选）· 职位详情 · 企业主页 · 核心特性 · 关于 · 帮助。

### 2.2 个人求职者端

| 模块 | 能做什么 |
|---|---|
| 工作台 | 求职进度、能力概览、最近面试、待办学习任务 |
| 简历中心 | **原文档库**（上传 PDF/DOCX + 内嵌预览）与**在线简历**（结构化编辑）双区管理；AI 解析、AI 诊断、一键优化改写（应用后跳回编辑页继续微调），解析结果不覆盖手工内容 |
| 能力诊断 | 六维雷达、技能达标线对照、能力历史趋势；无数据时显示空态 |
| 模拟面试 | 完整流程见第 3 章；支持考卷预览、断点续面、语音口述作答、题目朗读 |
| 面试记录 | 历史面试列表、报告回看、中止与重新面试 |
| 成长中心 | 跨场次成长曲线与薄弱项分布 |
| 学习路线 | 分阶段任务、产出物、推荐资源、进度打卡 |
| 求职计划 | 收集外部/平台岗位入计划，按本人简历分析技能覆盖与缺口，整理求职信、跟进草稿与 STAR 素材，记录进度与截止提醒 |
| 投递管理 | 官网投递入口与投递状态记录、历史投递 |
| 题库收藏 | 收藏题目、收藏题回看 |
| 通知与设置 | 站内通知（含实时推送）、账号与偏好设置、**个人自带模型配置** |

### 2.3 企业招聘端

招聘工作台 · 岗位管理与 AI 解析 JD 发布 · 岗位编辑 · 候选人列表（按匹配度与投递时间，含简历快照与能力档案）· 候选人详情 · 面试看板阶段流转 · 面试安排与邀约 · 结构化面试评价 · 人才库 · 招聘数据分析 · 企业设置与成员管理。

企业侧可见的候选信息均来自**投递时保存的快照**，不做推断与虚构，也不可见候选人的私密训练数据。

### 2.4 平台治理后台

运营总览 · 用户治理 · 企业治理 · 资质审核 · 岗位审核 · 投诉处置 · 内容治理 · **题库管理**（批次审核放行、覆盖度视图）· AI 引擎配置与脱敏调用日志 · 安全审计。管理员使用独立登录入口 `/admin/login`，与业务端隔离。

## 3. 模拟面试全流程

```
创建面试 ──▶ 开场引导 ──▶ 逐题作答 ⇄ 自适应追问 ──▶ 反问环节 ──▶ 交卷结算 ──▶ 诊断报告 ──▶ 学习路线
（岗位/JD/简历/   （面试官问候 +    （限时·暂停·跳过·       （候选人提问，     （六维评分 +       （薄弱项
  模式/难度/题量）  须知 + 开始）     语音·断点续面·幂等）      仅记录不计分）      逐题对照）        自动补齐）
```

**创建**：选择岗位（自动带出 JD，可手改）、挂接简历、选择面试模式（综合/技术/项目深挖/行为/压力）、难度与题量；**支持先预览考卷再开考**，预览顺序即实际出题顺序。

**作答**：
- 逐题限时并给出临场提示；参考答案要点**作答中不下发**（闭卷），交卷后才在报告里对照。
- 用时由服务端计时，暂停时长不计入；超时只轻扣、不归零。
- 整场不设硬性截止时间，答完由本人主动交卷；刷新页面后按服务端状态恢复当前题号、已用时长与草稿。
- 支持语音口述转写（浏览器原生能力）与题目朗读；识别失败时给出分级诊断提示（区分设备问题与网络问题）。
- 支持跳过、暂停、中止归档；重复提交不会重复评分。

**自适应追问**：每题评分后由模型给出下一步动作（追问/深挖/补基础/换题/结束等），答得好追加同技能更高难度题，答得差追加更低难度或换题；每场追问有上限，卷面可区分原卷题与追问题。

**反问环节**：逐题作答结束后进入反问，候选人最多提 3 个问题。该环节**只登记提问内容，不调用模型作答、不点评、不计分、不占时**——保留"你有什么想问我的吗"这一步流程真实感，同时不因"是否提问"惩罚内向型候选人。记录进入报告的「反问环节记录」区块。

**报告**：六维能力雷达、总分与等级、逐题得分与评分证据、参考答案要点对照、用时与超时分析、追问与反问记录、优势/短板/建议/总结，并标注本场评分与报告的实际来源（真实模型 / 模拟 / 规则）。

**学习路线**：薄弱项自动汇入能力画像，生成含产出物与推荐资源的分阶段任务，可在成长中心跟踪完成度。

## 5. 运行方式

### 5.1 Windows 一键启动

双击 `一键打开.bat`（自动检查依赖、启动前后端、就绪后打开浏览器）；`一键关闭.bat` 停止服务。日志在 `logs/`。

### 5.2 手动启动

```powershell
# 后端（端口 8000，含热重载）
cd backend && ..\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload

# 前端（新终端；Vite 已代理 /api、/ws、/uploads → 8000）
cd frontend && npm run dev
```

- 前端：http://localhost:5173　·　接口文档：http://127.0.0.1:8000/docs
- 环境变量均可选，见 `.env.example`；`AI_MODE`（REAL/MOCK）、`DATABASE_URL`、`SECRET_KEY`（生产必改）
- **不配置任何模型密钥也能完整体验**（内置确定性 Mock 引擎）

### 5.3 首次准备（顺序不可颠倒）

```powershell
# ① 数据库迁移（后端启动时也会自动执行；手动执行更直观）
cd backend
..\.venv\Scripts\python.exe -m alembic upgrade head

# ② 灌题库（321 题，按批次登记，新批次需管理端放行）
..\.venv\Scripts\python.exe scripts\seed_question_bank.py

# ③ 灌演示数据（23 用户 / 20 岗位 / 27 场面试）
..\.venv\Scripts\python.exe scripts\seed_demo.py
```

> **迁移必须先于灌库**：建表语句不会为已存在的表追加新列，跳过迁移直接灌库会因缺少 `batch` 列报错。

### 5.4 容器部署

`docker-compose.yml` 提供 MySQL 8 + Redis + 后端 + 前端四服务；生产切换数据库只需改 `DATABASE_URL`。
